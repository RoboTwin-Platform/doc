# RoboTwin 2.0 Usage Guide

This documentation provides a comprehensive guide to using RoboTwin 2.0: install, policy development and evaluation via [XPolicyLab](xpolicylab.md), data collection and configuration, automatic code generation for new tasks, API tutorial, language instruction generation, and digital asset annotation.

RoboTwin 2.0 and [RoboDojo](https://robodojo-benchmark.com/) share deployment via [XPolicyLab](https://github.com/XPolicyLab/XPolicyLab): one policy-serving / eval stack across both benchmarks (single-task, multi-GPU, and remote server + local sim).
